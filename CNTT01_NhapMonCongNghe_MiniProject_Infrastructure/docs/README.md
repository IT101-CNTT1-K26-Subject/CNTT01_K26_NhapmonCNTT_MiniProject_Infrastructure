**Hệ thống quản trị hạ tầng GreenTech K26**  
Hệ thống tự động hóa quản lý hạ tầng, lọc nhật ký sự cố và đối soát tài nguyên phần cứng cho các trạm cảm biến IoT ngoài trang trị.  
   
    
## **Checklist kiểm tra thiết bị định kỳ**  
- Kiểm tra kết nối mạng của các trạm cảm biến IoT  
- Kiểm tra dung lượng RAM khả dụng trên máy chủ trung tâm  
- Chạy script auto_report.bat để trích xuất danh sách lỗi  
- Sao lưu báo cáo sự cố vào thư mục backup/
